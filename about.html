About This Project

WebDev Project is a simple, hand-coded website built with plain HTML, CSS, and JavaScript — no frameworks, no page builders. It started as our first web development activity for Web Development & Web Design at West Visayas State University, and we kept building on it as a way to actually understand what happens underneath the tools most people start with.

Everything here was written from scratch: the layout, the styles, and the small bits of interactivity. If something looks simple, that is on purpose. We wanted to learn the fundamentals properly before reaching for shortcuts.

What We Used

  • HTML5 — page structure and semantic markup
  • CSS3 — custom stylesheet, Flexbox layout, responsive spacing
  • JavaScript — DOM interaction and event handling
  • Git & GitHub — version control and collaboration
  • VS Code — our editor of choice

What We Learned

Starting from an empty file teaches you things a template cannot. We learned how a browser reads a document top to bottom, why the box model matters more than it first appears, and how quickly a stylesheet turns messy without naming conventions. We also learned that "it works on my screen" is not the same as "it works."

This project is still a work in progress, and we plan to keep improving it as we learn more.
